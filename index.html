開發中的校園服務原型

Campus One

把課表、訊息、地圖和校園服務接在同一個 App 裡，同時提供 Web 介面。

  • 行動端與 Web 共用資料型別和角色規則。
  • 權限檢查涵蓋頁面導向、後端與 Firebase rules。

部分流程使用示範資料；外部服務串接依環境與憑證而定，不是正式校務系統。

訊息投遞模擬器

Relaylab

同一筆資料已經寫入，確認訊息卻遺失了；再次投遞時，會不會重複寫入？

  • 逐步查看投遞、租約到期與重試，再用相同種子重播。
  • 切換冪等寫入，區分「再次收到訊息」與「再次執行操作」。

TypeScript · 離散事件模型 · CLI

Retail Ops DSS

用銷量預測推算補貨和人力需求，並實作門市範圍與角色授權。

  • 以時間切分資料，比較預測模型與基準誤差。
  • 提供補貨操作、權限檢查與稽核紀錄。
