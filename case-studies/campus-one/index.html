Campus One

整合課表、訊息、地圖與校園服務的跨端應用。這頁整理行動端、Web、後端的程式結構，以及角色權限和測試方式。部署與外部服務串接的狀態以程式庫紀錄為準。

程式碼 程式導讀

使用情境

上下文分散

課表、公告、LMS、群組訊息與校園服務各自存在，使用者要自己拼出今天的優先順序。

角色不同

學生、教師、職員與管理者不能只換首頁文案；入口、資料可見範圍與可執行動作都不同。

服務會失效

外部 LMS、交通、校務或 AI provider 不保證永遠可用，產品需要處理服務暫時不可用的情況。

驗證方式

Expo + Next.jsMobile / Web 兩個主要 client surface
FirebaseFunctions + Firestore + Storage rules
Shared TS共用 contract 與角色規則
Mobile Jest回歸測試結果與可下載報告以每次 CI artifact 為準
Web / Functions / Rules獨立測試邊界；每次實際測試數見 CI 紀錄
CI gateslint、typecheck、security、build 與測試分開；數字與已知債務可追到 evidence page

AI 輔助功能的範圍

預定用途

  • 整理與摘要
  • 依授權上下文提供建議
  • 產生下一步候選動作
  • 在低風險流程中協助導航與草稿

權限限制

  • 直接讀所有使用者資料
  • 跳過角色與資料權限
  • 把高敏感 action 直接寫入
  • 把模型回答當校務資料來源
